

# 🐹 golang-studies-2026

Dejando .NET y sumergiéndome de lleno en Golang.

# 🧭 Acerca del proyecto
Este repositorio es mi cuaderno de estudios de Go.
Vengo del ecosistema .NET (C#) y estoy aprovechando este viaje para entender no solo la sintaxis, sino la filosofía detrás de Go — concurrencia nativa, simplicidad forzada, rendimiento sin ceremonia.
La idea es cubrir desde los tipos más básicos hasta los patrones más avanzados, documentando el camino.

## 🆚 .NET → Go: Mapa mental
 
| Concepto .NET | Equivalente en Go |
|---|---|
| `class` | `struct` + métodos |
| `interface` | `interface` (implícita!) |
| `IEnumerable` | `slice` / `channel` |
| `async/await` | `goroutine` + `channel` |
| `try/catch` | retorno de `error` |
| `null` | valores cero + punteros |
| `generics (C#)` | generics (Go 1.18+) |
| `namespace` | `package` |
| `NuGet` | `go get` / `go.mod` |

## 💡 Filosofía del proyecto
 
- Un concepto por carpeta, simple y enfocado
- Comentarios en el código explicando el **porqué**, no solo el **qué**
- Comparaciones con C# donde tenga sentido
- Sin frameworks, sin magia — solo Go puro
