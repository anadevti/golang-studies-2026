# Go Studies Roadmap

A progressive path for this repository.

## 01 — Fundamentos

- variables and zero values
- constants
- types and type inference
- functions
- control flow
- `defer`
- pointers
- structs and methods
- packages and visibility

## 02 — Data structures

- arrays
- slices
- maps
- strings and bytes
- composition
- interfaces and method sets

## 03 — Errors and testing

- `error`
- wrapping and comparison
- custom errors
- unit tests
- table-driven tests
- benchmarks
- coverage
- race detector

## 04 — Go for backend

- HTTP
- handlers and middleware
- JSON
- context
- timeouts and cancellation
- database access
- configuration
- logging and observability

## 05 — Concurrency

- goroutines
- channels
- synchronization
- worker pools
- pipelines
- backpressure
- cancellation
- goroutine leaks

## 06 — Production Go

- profiling
- memory allocation
- garbage collection
- graceful shutdown
- retries and idempotency
- resilience and failure handling
- performance measurement

## 07 — Architecture

- package boundaries
- dependency inversion
- ports and adapters
- pragmatic Clean Architecture
- testability
- trade-offs and when not to abstract

## Study rule

For each topic, prefer this progression:

```text
Understand → Predict → Experiment → Implement → Test → Explain → Apply in production
```

The repository is a learning journal, so unfinished exercises and wrong first attempts are useful artifacts.
